# 汪汪小精靈 學習小伙伴（網頁版）

給國小到高中學生用的學習夥伴：英語單字闖關、自我打卡、養成夥伴。平板、Chromebook、電腦的瀏覽器都可以用，第一次開啟後也能離線使用。

- **學生用**：https://linyuchi58.github.io/puppy-study/
- **家長蓋章頁**：https://linyuchi58.github.io/puppy-study/parent.html （請從孩子裝置上的 QR Code 開啟）

## 學習紀錄存在哪裡

- 學習紀錄**只存在使用者自己的裝置**（瀏覽器裡），不會上傳到任何地方。
- 程式每天自動留一份備份，保留最近 7 天，可以在「搬家碼／備份」頁還原。清除瀏覽器資料時，紀錄和自動備份會一起消失，重要的紀錄請另外下載備份檔。
- 家長蓋章不需要伺服器：要給家長看的內容直接寫在 QR Code 網址的「#」後面，這一段不會送到網站。

這是一位國小老師的業餘作品，**不提供使用者支援**，紀錄遺失時也無法幫忙找回。
